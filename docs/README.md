▎♟️ Шахматы

Это простая игра в шахматы, реализованная на Python с использованием библиотеки Pygame. Игра позволяет двум игрокам сражаться на одном компьютере.

▎🌟 Особенности

• Поддержка базовых правил шахмат.

• Графический интерфейс с использованием Pygame.

• Проверка допустимости ходов фигур.

• Автоматическая трансформация пешки в ферзя при достижении конца доски.

• Определение победителя при захвате короля.

▎📋 Требования

• Python 3.6 или выше

• Библиотека Pygame

▎🎮 Игровой процесс

1. Игра начинается с классической шахматной расстановки.

2. Игроки по очереди делают ходы своими фигурами.

3. Нажмите на фигуру, чтобы выбрать её, затем нажмите на допустимое поле для перемещения.

4. Игра заканчивается, когда король одного из игроков захвачен.

▎🛠️ Описание классов и методов

▎Классы

▎ChessPiece

Абстрактный базовый класс, представляющий шахматную фигуру.

Атрибуты:

• x: Координата x (столбец) на доске.

• y: Координата y (строка) на доске.

• color: Цвет фигуры ('white', 'black' или 'empty').

• paths: Возможные направления движения фигуры.

• alive: Флаг, указывающий, жива ли фигура.

Методы:

• takeAttackFields(x, y): Вычисляет все возможные поля для атаки фигуры с позиции (x, y).

▎EmptyField

Класс, представляющий пустое поле на шахматной доске. Наследуется от ChessPiece.

▎Pawn

Класс, представляющий пешку. Наследуется от ChessPiece.

Особенности:

• Переопределяет метод takeAttackFields для расчёта специальных правил хода пешки.

▎Rook

Класс, представляющий ладью. Наследуется от ChessPiece.

▎Knight

Класс, представляющий коня. Наследуется от ChessPiece.

▎Bishop

Класс, представляющий слона. Наследуется от ChessPiece.

▎Queen

Класс, представляющий ферзя. Наследуется от ChessPiece.

▎King

Класс, представляющий короля. Наследуется от ChessPiece.

▎ChessBoard

Класс, представляющий шахматную доску и управляющий состоянием игры.

Атрибуты:

• board: Двумерный список, представляющий клетки доски и содержащий объекты фигур.

• turn: Номер текущего хода.

Методы:

• setup_board(): Устанавливает начальные позиции фигур на доске.

▎Renderer

Класс, отвечающий за визуализацию шахматной доски и фигур, а также за обработку взаимодействия с пользователем.

Атрибуты:

• screen: Поверхность Pygame для отображения.

• board: Ссылка на шахматную доску.

• selected_piece: Выбранная пользователем фигура.

• piece_images: Словарь с изображениями фигур.

• valid_moves: Список допустимых ходов для выбранной фигуры.

• turn: Номер текущего хода.

• whiteWin, blackWin: Флаги победы белых или чёрных.

Методы:

• draw_board(): Отрисовка шахматной доски.

• load_images(): Загрузка изображений фигур.

• draw_pieces(): Отрисовка фигур на доске.

• pawnTransform(): Трансформация пешки в ферзя.

• winner(winner): Отображение победителя.

• handle_click(pos): Обработка щелчков мыши.

| Установка
Клонируйте репозиторий

Перейдите в директорию проекта:

cd Chess

Установите необходимые пакеты:

pip install pygame

▎⚠️ Примечания

• Движение фигур: Реализованы только базовые правила движения. Продвинутые правила, такие как рокировка, взятие на проходе и проверка шаха/мата, не реализованы.

• Трансформация пешки: Пешки автоматически превращаются в ферзя при достижении противоположного конца доски.

• Конец игры: Игра объявляет победителя при захвате короля.
